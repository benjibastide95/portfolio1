Module d'authentification

// PHP 8 EN ARCHITECTURE MVC, SANS FRAMEWORK

MODULE PHP 8

À PROPOS

Module d'authentification complet écrit en PHP 8, organisé en MVC, sans framework ni Composer. L'objectif : comprendre comment fonctionne une authentification de bout en bout, en séparant clairement les modèles, les vues et les contrôleurs.

ARCHITECTURE

  • Front controller : un seul point d'entrée, public/index.php, reçoit toutes les requêtes.
  • Réécriture d'URL avec un fichier .htaccess.
  • Séparation Modèle / Vue / Contrôleur.
  • Aucune dépendance externe : ni framework, ni Composer.

TECHNOLOGIES

PHP 8 MVC MySQL Sessions Apache
